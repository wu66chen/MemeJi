# Mimu 表情包 GPT-image-2 提示词（18 张定稿）

## 使用参数（每张都一样）

| 参数 | 值 |
|------|-----|
| 模型 | GPT-image-2 |
| 参考图 | `branding/memeji-icon.png`（圆形透明底定妆图） |
| input_fidelity | **high**（锚定参考图，保形象一致） |
| background | transparent |
| output_format | png |
| size | 1024x1024 |

**迭代规则（单变量）**：某张不满意时，只修改该条的「动作与表情」段中的单一变量（只改动作 / 只改表情 / 只改文字位置），其余一字不动重新生成，避免形象漂移。

## 全局硬约束

- 青蛙帽**只是服装**：可与角色互动（缩进去、捏帽檐），但绝不拟人化、绝无独立表情或动作。
- 无字的 13 张：提示词末尾明确禁止出现任何文字。
- 有字的 5 张（A4/A7/C1/C5/C7）：文字内容、位置写死，要求准确无错字、简洁圆体字。
